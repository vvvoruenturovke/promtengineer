# 🧠 Конструктор промптов

**Простой и мощный инструмент для создания идеальных промптов для нейросетей.**  
Работает прямо в браузере, не требует установки, все данные хранятся локально.

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🎯 **Три типа промптов** | Языковая модель, генерация изображений, генерация кода |
| 📦 **Встроенные шаблоны** | Маркетинг, отладка, обучение, киберпанк, акварель, Python, React, FastAPI |
| 🔖 **Свои шаблоны** | Сохраняйте любые настройки как персональные пресеты |
| 💾 **Автосохранение** | Все поля сохраняются в localStorage — данные не теряются |
| 📜 **История промптов** | Последние 20 промптов всегда под рукой, можно загрузить любой |
| 🔍 **Подсказки при наведении** | Для каждого поля — примеры и рекомендации |
| 🎨 **Подсветка синтаксиса** | Markdown-разметка и код выглядят красиво |
| 📋 **Копирование** | Одна кнопка — и промпт в буфере обмена |
| 💾 **Скачивание** | Сохранение промпта в `.txt` файл |
| 🧹 **Очистка полей** | Текущая вкладка или всё сразу |

## 🚀 Быстрый старт

### Способ 1 — скачать и открыть (локально)

1. Скачайте файл `index.html`
2. Откройте его в любом современном браузере (Chrome, Firefox, Edge, Safari)
3. Готово к использованию!

### Способ 2 — онлайн-хостинг (бесплатно)

1. Перейдите на [Netlify Drop](https://app.netlify.com/drop) или [GitHub Pages](https://pages.github.com/)
2. Перетащите файл `index.html`
3. Получите ссылку для публичного доступа

## 📖 Как пользоваться

### 1. Выберите тип задачи
- 💬 **Языковая модель** — для чатов, текстов, анализа
- 🎨 **Генерация изображений** — для Midjourney, DALL-E, Stable Diffusion
- 💻 **Генерация кода** — для Copilot, ChatGPT Code Interpreter

### 2. Заполните поля
Каждое поле сопровождается **подсказкой при наведении** — там есть примеры.

### 3. Используйте шаблоны
- **Серые бейджи** — встроенные шаблоны, работают сразу
- **Фиолетовые бейджи** — ваши сохранённые шаблоны

### 4. Соберите промпт
Нажмите **«Собрать промпт»** — результат появится справа.

### 5. Сохраните результат
- 📋 **Копировать** — в буфер обмена
- 💾 **Скачать** — текстовый файл

### 6. Работа с историей
- Справа внизу — все собранные промпты
- Кликните по любому — загрузится в окно вывода
- 🗑️ — удалить запись

## 🛠️ Технологии

| Технология | Назначение |
|------------|------------|
| HTML5 | Структура страницы |
| TailwindCSS | Стилизация (быстрая и удобная) |
| JavaScript (ES6+) | Логика, LocalStorage, динамика |
| Highlight.js | Подсветка синтаксиса |

**Никаких серверов, бэкендов, API-ключей.** Всё работает в вашем браузере.

## 📁 Структура хранения данных (localStorage)

| Ключ | Что хранит |
|------|------------|
| `prompt_builder_form_data` | Текущие значения всех полей |
| `prompt_builder_custom_presets` | Пользовательские шаблоны |
| `prompt_builder_history` | История собранных промптов |

## 🎨 Примеры использования

### Пример 1: Создание поста для соцсетей
1. Вкладка: **Языковая модель**
2. Шаблон: **Маркетинг**
3. Дополните своими данными
4. Собрать → Копировать → Вставить в ChatGPT

### Пример 2: Генерация изображения в стиле киберпанк
1. Вкладка: **Генерация изображений**
2. Шаблон: **Киберпанк**
3. Измените объект на свой
4. Собрать → Копировать → Вставить в Midjourney

### Пример 3: Написание функции на Python
1. Вкладка: **Генерация кода**
2. Шаблон: **Python функция**
3. Измените задачу под себя
4. Собрать → Копировать → Вставить в Copilot

## 🔧 Кастомизация

### Добавление своих встроенных шаблонов

В коде найдите объект `builtInPresets`:

```javascript
const builtInPresets = {
    lm: [  // для языковой модели
        { name: "Название", fields: { lm_role: "...", lm_task: "..." } }
    ],
    img: [ // для изображений
        { name: "Название", fields: { img_object: "...", img_style: "..." } }
    ],
    code: [ // для кода
        { name: "Название", fields: { code_lang: "Python", code_task: "..." } }
    ]
};
